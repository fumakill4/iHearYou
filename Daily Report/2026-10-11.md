## Limits and usage

Controlled test results do not guarantee that every disturbance disappears. Other speakers, heavy reverberation, and clipping may remain audible. Use Strong mode for maximum attenuation, select iHearYou Microphone on the voice-over site, and keep the app running. If macOS requests permission after a build update, the user must click Allow directly; an existing driver does not need to be reinstalled.

This build uses local ad-hoc code signing. The i729 signature is embedded in the code; it is not a paid Developer ID certificate.
