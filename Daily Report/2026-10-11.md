# Daily Report — 11 Oktober 2026

Dibuat oleh **i729**. Signature: i729.

## Hasil pekerjaan

- iHearYou 1.1 dibuat sebagai aplikasi macOS independen tanpa trial, dengan pemrosesan suara lokal dan signature i729 pada kode integrasi.
- Panel ringkas tersedia melalui ikon menu bar/floating logo. Roda gigi membuka satu jendela Settings. Pilihan System, Light, Dark dan floating control tersimpan.
- Floating control menampilkan status mikrofon, meter output, timer, tombol rekam dan drag handle; klik pertama ditangani dengan benar.
- icon.png dipakai untuk ikon aplikasi macOS. Metadata nonvisual gambar dibuang dari source yang dibagikan; piksel logo dipertahankan.
- Mesin diperbarui menjadi DPDFNet2 48 kHz. Natural membatasi peredaman 20 dB; Seimbang 30 dB; Kuat memakai seluruh hasil model. Delay algoritmik 50 ms ditambah buffer/perangkat.
- Mikrofon virtual mengirim hasil pemrosesan ke browser. Perekam lokal menyediakan preview dan unduhan; input untuk voice-over adalah iHearYou Microphone.
- Source sudah diunggah ke repo **Public** [iHearYou](https://github.com/hittoukiri-design/iHearYou) sesuai permintaan. Rekaman, log, cache, data akun, path pribadi dan preferensi lokal dikecualikan. Identitas author Git dan copyright kode memakai i729.

## Verifikasi

8 pengujian DSP lulus tanpa kegagalan. Build produksi dan build dari salinan source bersih berhasil, termasuk unduhan dependency dengan checksum, ikon, driver dan pemeriksaan code signing lokal.

Pada fixture ucapan dengan enam tepukan yang tumpang tindih, pengurangan efek tepuk naik dari 9,66 dB (RNNoise lama) ke 14,64 dB. Tepukan terburuk naik dari 4,04 ke 10,05 dB. Level ucapan bersih berubah -0,063 dB; tidak ada error pemrosesan atau sampel input terbuang pada probe kode produksi.

UI panel, Settings, tema, floating dan persistensi pilihan diperiksa langsung. Build terakhir sudah aktif pada mode Kuat dengan meter audio hidup. Jalur virtual menerima 139.200 sampel dalam probe 3 detik. Brave berhasil merekam dan mengunduh audio Opus 48 kHz berdurasi 8,4 detik dari perangkat virtual. Tidak ada task MargVoice atau audio pribadi yang diunggah.

## Batas dan penggunaan

Hasil pengujian terkontrol tidak menjamin semua gangguan hilang atau kesetaraan dengan Krisp. Pembicara lain, gema berat dan clipping dapat tetap terdengar. Gunakan mode Kuat untuk peredaman maksimum, pilih iHearYou Microphone pada situs voice-over, dan biarkan aplikasi berjalan. Jika macOS meminta izin setelah build diperbarui, pengguna perlu menekan Allow langsung; driver yang sudah terpasang tidak perlu diinstal ulang.

Code signing build ini bersifat ad-hoc lokal; signature i729 tertanam pada kode, bukan sertifikat Developer ID berbayar.
