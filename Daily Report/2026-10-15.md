## Delivered changes

- Bluetooth capture moved from an AVAudioEngine input tap to input-only AUHAL. Format changes reconnect with bounded attempts after device settling.
- Timer and CoreAudio callbacks dispatch safely to MainActor; DSP lifetime is retained across delayed render/processing callbacks.
- The first model pass on headset speech was rejected after the user confirmed clear Original / damaged Clean audio. The interim Bluetooth profile preserved the headset signal with a quiet-background gate; the user confirmed clear, unbroken audio but reported residual phone-video voices, barking, and environmental noise. This triggered a separate narrowband denoiser revision.
- Full-band input uses DPDFNet2, a linear-phase low-rumble filter, Silero speech activity gating with pre-roll/release, and no raw noise mix-in.
- Native acoustic echo processing is used for built-in microphones with compatible physical system outputs; AGC is disabled. Virtual/aggregate inputs are excluded to prevent direct desktop-audio capture.
- Monitoring uses device-rate AUHAL output with its own resampling lane.
- Saved WAV tails are drained; saving opens Recordings; playback automatically stops an idle mic session.
- A local repaired comparison pair was generated from the user's supplied recording; existing recordings were preserved.
