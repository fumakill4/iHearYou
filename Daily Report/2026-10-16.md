# Daily Report — 2026-10-16

Created by i729. Signature: i729.

## iHearYou 1.4.0, build 7

Prepared the user-tested AirPods fixes for GitHub publication. Bluetooth capture uses input-only AUHAL with bounded format-change recovery. DPDFNet2 at 16 kHz and a bounded GTCRN speech-safety path improve headset noise reduction; full-band microphones retain their separate 48 kHz path. Recording tails, saved-file discovery and playback, monitoring sample rates, and callback lifetimes were corrected.

The user confirmed stable AirPods capture, clear unbroken Clean recordings, and better results than the previous build. Background phone-video speech remains audible. No speaker enrollment or target-speaker extraction is implemented, so owner-only isolation remains an unresolved requirement. No guarantee is made that overlapping noise or acoustic notifications disappear.

## Validation

15 automated tests passed. The exact-source headset regression passed: Studio reduced the effect of overlapping synthetic fan noise by 15.60 dB, dog barking by 16.39 dB, and vacuum noise by 12.79 dB on local controlled fixtures. Bandwidth-matched speech SI-SDR was 21.93 dB with a −0.22 dB level change. Processing/input-drop counters remained zero. These measurements do not establish identical performance in every room.

The tested app is installed in `/Applications/iHearYou.app`; a distributable raw app remains in `dist/iHearYou.app`. The current native icon was exported to `icon.png` and `dist/iHearYou.png` without changing the design. Packaging now includes the PNG in SHA256SUMS. PNG fallback builds were checked while preserving the user's existing deletion of the local ICNS source; the remote ICNS source is retained.
