# iHearYou design

Created by **i729**. Signature: i729.

The menu bar icon opens a compact 360 x 646 control panel. The header gear opens a separate settings window. Noise controls and microphone selection stay immediately accessible; device, recording and browser actions operate the real session. This follows the user-provided interaction reference with independent iHearYou branding and no trial/account placeholders.

System, Light and Dark themes apply to the panel, settings and floating control and persist across launches. Adaptive native colors preserve text legibility; violet identifies active cancellation and primary actions. The supplied `Real app logo.icns` provides the macOS application icon. System symbols identify specific actions in compact controls.

English is the default app language. Settings → Appearance → Language offers English and Indonesian, and saves the choice immediately. The selection applies to native controls and messages, the local browser recorder, and the iPhone Safari receiver. Both browser pages provide a language selector as well. Repository documentation uses English.

The small vertical floating control stays above ordinary windows across Spaces. Its drag handle uses native window dragging; position persists and is clamped to visible screen bounds. Its microphone, recording, timer and clean-audio meter reflect the same model as the menu panel.

Settings separates detailed audio controls, recordings and setup guidance. Input and monitor devices can change during capture; the session restarts with the selected devices, saving an active WAV recording and continuing in a new file. Permission, unavailable driver/device, loading, recording and model failures are explicit. Native keyboard focus, shortcuts and minimum settings size support accessibility. Level history represents actual RMS energy rather than a synthetic waveform or identity detector.

The local browser recorder has clear device selection, permission/error states and local playback/download. It does not trigger project submission or upload. The UI filter skills app-builder, antislop and antislop-ui informed the native layout and truthful control states.
